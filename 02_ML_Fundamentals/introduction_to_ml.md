
# Introduction to Machine Learning

## Definition
Machine Learning is a branch of Artificial
Intelligence that enables computers to learn
from data and make predictions or decisions
without explicit programming for every task.

## Relationship
- Artificial Intelligence (AI)
- Machine Learning (ML)
- Deep Learning (DL)

Deep Learning is a subset of Machine Learning,
and Machine Learning is a subset of AI.

## Types of Machine Learning
1. Supervised Learning
2. Unsupervised Learning
3. Semi-Supervised Learning
4. Reinforcement Learning

## Applications
1. Healthcare
2. Banking and Finance
3. Education
4. Transportation
5. E-commerce
6. Communication Systems

## Learning Objective
Understand the fundamentals and different
types of Machine Learning.
